# 技术说明与验证范围

系统由经营者网页、Python业务后端、SQLite持久化、AgentArts专业智能体及只读业务工具组成。资料、方案和证据按任务与版本关联；经营者确认后才能形成自己的行动安排。

确定性工具核验预算、库存、工时与现金情景，保留未知成本和待补证事项；工具通过不代表执行批准。互助交流属于经营者之间的信息交换，不构成效果承诺。

MCP服务采用ARM64容器及Streamable HTTP，已验证真实云端握手、工具发现、超预算计算、错误输入及未授权请求。真实现金智能体通过应用侧桥接发起核验并引用结果，原始记录随源码提供。此实现不是控制台原生MCP绑定。

testing/public-retail中的经营案例是构造的人民币场景，公开数据统计与构造参数分别标识。其他examples及测试资料均不代表真实商户收益。

本地规则和接口测试用于验证实现行为，不是AI总体准确率；小规模探索对照不证明多智能体普遍优于单智能体。真实经营收益、独立目标用户评测与长期公网运行不在本次技术验收结论范围内。
