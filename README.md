# 逆势重生

基于华为云 AgentArts 的实体小微商户经营决策支持项目。库存、客户、现金与经营统筹角色围绕经营资料进行核查、方案分析与交叉复核；后端独立计算现金、预算、成本与工时约束，网页支持资料上传、方案比较、行动记录、大字模式和商户互助。

## 本地运行

安装 Python 3.11 或更新版本，在源码目录执行：

```sh
python start_public.py
```

浏览器自动打开，注册自己的新账号。保持进程运行。默认关闭云端调用，不需要密钥；各电脑独立启动的数据不自动同步。页面适配移动尺寸，默认监听本机地址，真实手机访问需另行配置可访问的部署入口。

## AgentArts 接入

四类角色提示词位于 `agentarts/prompts/`，接入说明见 `agentarts/SETUP.md`。配置示例位于 `config/`。使用自己的运行时、模型和凭据，本仓库不包含团队私有密钥。云端分析可能产生费用，需在应用中明确确认。

## 源码结构

- `rebirth/`：业务后端、账号隔离、社区、数据处理、模型协议、工具与日程。
- `dist/`：经营工作台、账号、互助广场等页面与脚本。
- `design-preview/dist/`：首页样式、脚本与图片素材。
- `agentarts/`、`knowledge/`：角色提示词、平台接入说明和本地知识条目。
- `tests/`、`testing/`：自动化测试与实验执行脚本；实验脚本可能需要独立的本地配置和资料，不默认触发云调用。
- `examples/`：示例及构造资料，不代表真实商户收益。
- `docs/`：冻结版技术说明和验证范围。

## 验证范围

冻结版最近完整后端回归368项、前端61项、本地固定案例15项通过。规则通过率不是AI总体准确率，构造经营测算不是商户真实增收。具体云端运行、失败及实验边界见docs。

本公开源码不包含账号数据库、真实上传资料、调用凭据、私用录制包或第三方Python运行时；不依赖外部临时测试链接。
